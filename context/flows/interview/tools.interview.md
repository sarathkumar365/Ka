# Interview questions: tools

1. Why can the model not write YAML or file paths? What does it send instead?
2. How do you show a diff without leaving the repo dirty if the user says no?
3. Two edits are proposed against the same file; the first is approved. What happens to the second, and why?
4. Why reload the data on every tool call instead of caching it?
5. Why is money returned as strings, and where is that enforced?
6. What makes ids "never reused" when records can be deleted?
7. How would you wrap these tools in MCP later without changing them?
